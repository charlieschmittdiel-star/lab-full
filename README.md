# lab-full

The full version of Gridiron Lab (football), Hardwood Lab (basketball, `hoops/`) and Pitch Lab (soccer, `soccer/`).
Plain HTML, CSS and JavaScript. Open `index.html` to play.

Access codes are checked against the owner's Google Sheet (`sheetlock.js`, settings at the top).
`owner-tools/` holds the script that goes in that Sheet. It is not part of the game download.
